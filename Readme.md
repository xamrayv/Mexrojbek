# Login Project

Ushbu loyiha foydalanuvchilarni ro'yxatdan o'tkazish hamda tizimga kirish (Authentication/Authorization) funksionalligini amalga oshirish uchun mo'ljallangan.

## 🚀 Xususiyatlari

* Foydalanuvchini tizimga kirishi (Login)
* Yangi foydalanuvchini ro'yxatdan o'tkazish (Sign Up)
* Ma'lumotlarni xavfsiz tekshirish (Validation)

## 🛠 Ishlatilingan texnologiyalar

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** (Loyiha turiga qarab o'zgartirishingiz mumkin: Node.js, Python, PHP, va h.k.)
